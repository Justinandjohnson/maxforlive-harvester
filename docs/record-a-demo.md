# Record a 20-second Ableton demo

**Goal:** one short clip where someone can see a Max for Live device and hear what it does.

- [ ] **Pick one device.** On the computer with Ableton Live, open a device you found with the Harvester. If you need one, follow [Try it on one device](../README.md#try-it-on-one-device).
- [ ] **Set up the shot.** Keep the device name and controls visible. For a synth, play a few notes. For an effect, loop a short phrase and toggle the effect so the difference is audible.
- [ ] **Check the sound.** In your screen recorder, enable system or application audio. Make a three-second test and play it back. Can you hear Live?
- [ ] **Record about 20 seconds.** Show the device, play the sound, and move one control so the viewer can hear the change. No narration or editing needed.
- [ ] **Hand it off.** Save the clip as MP4 or MOV, play it back once, then attach it to the Codex chat where you requested the GitHub review. You can upload from either computer.
