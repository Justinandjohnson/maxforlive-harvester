# Example output: CATALOG.md

This is a **real** catalogue produced by `scripts/categorize.ps1` against a library
of **410 installed devices**. It is here so you can see the shape of the output
before running it yourself, not as a fixed list to download.

Your own run produces different contents. The script reads the devices in your
User Library and writes the same three-column format:

| Device | What it does | Reach for it when |

Devices marked *inferred from name* are undocumented - the store listing had no
usable description, so the entry is a guess from the name alone. That honesty is
deliberate: a guess you can see is worth more than a confident lie.

# Max for Live Catalog

## Start here

- **Modulus1.4** — a full polyphonic synth with presets and sensible controls; the easiest place to confirm the whole library loads.
- **D-Emu1.0** — Minimoog Model D clone; instant bass and lead, no programming required.
- **Nepheton - Snare** — one 808 snare, standalone; drop it on a track and you have a usable sound in seconds.
- **Filament1.1** — polyphonic Karplus-Strong strings; the most immediately musical of the physical-modelling instruments here.
- **minormiracle** — chord player, sequencer and arpeggiator in one; start here if you want chords you did not play.
- **chordmonitorplusplus** — names the chord you are holding, on Push and in Live; fixes a set faster than theory study.
- **a-n-transient-shaper** — attack and sustain control for drums; the most obviously useful of the a-n effect set.
- **forge** — multiband saturation; makes a flat mix sound finished with four knobs.
- **pattern-machine** — arpeggiator that produces polyrhythms and polymeters; good first stop for something unexpected.
- **lufs-mini** — real-time loudness meter; answers "is this actually loud enough" without leaving Live.
